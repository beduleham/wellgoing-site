# 문의 폼 → 구글 시트 연결

홈페이지 「문의하기」와 「파트너 문의」 폼이 보낸 내용이 구글 시트에 한 줄씩 쌓이고, 알림 메일이 옵니다.
처음 한 번만 설정하면 됩니다 (약 5분).

## 1. 시트 만들기
1. 회사 구글 계정으로 https://sheets.new 접속 → 빈 시트가 열립니다
2. 왼쪽 위 제목을 `웰고잉 홈페이지 문의` 로 바꿉니다

## 2. 스크립트 붙여넣기
1. 메뉴 **확장 프로그램 → Apps Script**
2. 열린 편집기의 `Code.gs` 내용을 전부 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여넣기
3. 맨 위 `NOTIFY_EMAIL` 이 알림 받을 메일 주소인지 확인 (기본 wellgoing@wellgoing.kr)
4. 저장 (Ctrl+S / ⌘S)

## 3. 처음 실행 (권한 승인)
1. 편집기 위쪽 함수 선택에서 **setup** 선택 → **실행**
2. 「승인 필요」 → **권한 검토** → 본인 계정 선택
3. 「Google에서 확인하지 않은 앱」 화면이 나오면 **고급 → (안전하지 않음)으로 이동** → **허용**
   - 본인이 만든 스크립트라 나오는 일반적인 안내입니다
4. 시트로 돌아가면 「문의」「파트너 문의」 탭이 생겨 있습니다

## 4. 웹 앱으로 배포
1. 편집기 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → 유형 **웹 앱**
3. 설정
   - 설명: `웰고잉 홈페이지 문의`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**  ← 홈페이지 방문자가 보낼 수 있도록
4. **배포** → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사

## 5. 사이트에 연결
`assets/js/main.js` 맨 위 `FORM_ENDPOINT: ''` 따옴표 안에 위 URL을 넣고 커밋·push.

## 운영
- 「처리 상태」 열: 신규 → 진행 중 → 완료 (드롭다운). 「메모」 열은 자유롭게
- 알림 메일에서 **답장**하면 문의자에게 바로 갑니다
- 받는 사람 추가: `NOTIFY_EMAIL = 'a@x.com,b@y.com'` → 저장 후 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** (URL은 그대로)
- 스크립트를 고친 뒤에는 항상 위처럼 **새 버전으로 배포**해야 반영됩니다
- 무료 계정 메일 알림 한도: 하루 100통
- 전송이 실패하면 방문자 화면에 「메일로 보내기」 링크가 떠서 문의가 유실되지 않습니다
